# ConfigTool

برنامه‌ی ویندوز برای پیدا کردن، تست و اتصال به کانفیگ‌های رایگان (vmess / vless / trojan / ss / hysteria2 / tuic / anytls).
کانفیگ‌ها از منابع عمومی GitHub و کانال‌های اضافه‌شده جمع می‌شن، تست می‌شن و بهترین‌شون وصل می‌شه.

## ساختار
- `app/cfgweb.py` هسته‌ی برنامه: سرور محلی و رابط وب
- `app/cfgscan.py` جمع‌آوری و تست کانفیگ‌ها
- `app/cfgforge.py`, `app/report.py` ابزارهای کمکی و گزارش
- `app/ui.html` رابط کاربری

## نسخه‌ی آماده
فایل exe از بخش **Releases** دانلود می‌شه. exe شامل پایتون، xray و sing-box هم هست.

## اجرا از سورس
پایتون ۳.۱۲ و فایل‌های `xray` و `sing-box` کنار پروژه لازم‌ن (ساختار پوشه‌ها مثل داخل exe).

## هشدار
این برنامه کانفیگ‌های عمومی و ناشناس رو تست می‌کنه. مسئولیت استفاده با خود شماست و هر کانفیگ می‌تونه ترافیک رو ببینه.
