تغییرات «تکامل امن» برای ConfigTool (نسخه‌ی ۲: گزارش کامل)

چطور نصب کنم؟
۱) توی گیت‌هاب، ریپوی CT_orginal رو باز کن.
۲) Add file ← Upload files رو بزن.
۳) پوشه‌های app و scripts و tests از همین زیپ رو بکش داخل صفحه (ساختار پوشه‌ها رو نگه می‌داره).
۴) پایین صفحه Commit changes رو بزن.
۵) صبر کن Actions فایل ConfigTool.exe رو بسازه و همون رو دانلود کن.

بعد از نصب:
- توی برنامه تب «تکامل» اضافه شده.
- یکی از دکمه‌های «گزارش کامل» رو بزن و فایلش رو توی چت Claude بفرست.
  فشرده: کوچیکه (چند کیلوبایت). متنی: همون اطلاعاته ولی خوانا برای هر چتی.
- Claude یه فایل .ctpatch بهت می‌ده؛ همون تب انتخابش کن و «نصب امن» رو بزن.
- اگه بعد از نصب چیزی خراب شد: «برگشت به نسخه‌ی قبل» یا «برگشت کامل به حالت اولیه».

نکته: وقتی نسخه‌ی تازه‌ی exe رو نصب کنی، وصله‌های قبلی خودکار کنار گذاشته می‌شن و باید گزارش تازه بسازی.
