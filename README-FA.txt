نسخه‌ی ویندوز (ریپوی CT_orginal) - به‌روزرسانی ۲

چطور نصب کنم؟
۱) توی گیت‌هاب، ریپوی CT_orginal رو باز کن.
۲) Add file ← Upload files رو بزن.
۳) پوشه‌های app و tests از همین زیپ رو بکش داخل صفحه (ساختار پوشه‌ها رو نگه می‌داره).
۴) پایین صفحه Commit changes رو بزن.
۵) صبر کن Actions فایل ConfigTool.exe رو بسازه و همون رو دانلود کن.

چی عوض شد؟
- ترتیب تست منبع‌ها: منبعی که قبلاً کانفیگ خوب داده جلوتر تست می‌شه، منبع بد خیلی کم، و منبع تازه هم شانس می‌گیره.
- (از به‌روزرسانی قبل) شناسه‌ی دقیق‌تر شبکه، یادگیری جدای هر شبکه، لیست واحد سرورها.
